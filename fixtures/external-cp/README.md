# External CP reference corpus

The seven files listed in `manifest.json` are local MDT server upload samples.
They are referenced in place and are **not copied into this repository**.

Local source directory:

`<local-external-cp-corpus>`

The files contain no embedded author or license metadata. Their provenance is
therefore recorded as "local MDT external-cp upload corpus" and their license
as "unknown/reference-only". Do not publish, redistribute, or use them outside
local tests without permission from the original authors.

Use the SHA-256 values in `manifest.json` to ensure the local corpus has not
changed before interpreting regression results.
